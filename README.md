# CampusCare – Campus IT Helpdesk

A small Flask + SQLite application for reporting and tracking campus IT support tickets, with Git, Jenkins CI and Docker support.

## Features
- Student ticket submission with category and description.
- Unique ticket ID generated by SQLite.
- Ticket tracking using ticket ID and email address.
- Admin sign-in and dashboard.
- Admin can update ticket status (`Pending`, `In Progress`, `Resolved`) and priority (`Low`, `Medium`, `High`).
- Dashboard counters.
- Automated unit tests.
- Jenkins pipeline and Docker image.

## Requirements
- Python 3.10 or later (tested with Python 3.13).
- Git.
- Docker Desktop for container build/run.
- Jenkins for the CI pipeline demonstration.

## Run on Windows (VS Code terminal / Command Prompt)

Open the project folder in VS Code. In the terminal, run:

```bat
py -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
waitress-serve --listen=127.0.0.1:5000 app:app
```

Then visit http://127.0.0.1:5000.

If using PowerShell, activate with:

```powershell
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, run this only in the current terminal session and activate again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

You can also run `python app.py` for local development. Waitress is used in the recommended run command.

## Demo admin login
- URL: http://127.0.0.1:5000/admin/login
- Demo password: `admin123`

This is a local academic demo credential. Change it before sharing or deploying the app. In Command Prompt:

```bat
set CAMPUSCARE_ADMIN_PASSWORD=your-new-password
set CAMPUSCARE_SECRET_KEY=use-a-long-random-secret
```

Then start the app from the same terminal. In PowerShell, use `$env:CAMPUSCARE_ADMIN_PASSWORD="your-new-password"` and `$env:CAMPUSCARE_SECRET_KEY="use-a-long-random-secret"`.

## Database
SQLite creates `campuscare.db` automatically in the project folder when the app starts. The database file is ignored by Git so local student data is not committed.

## Docker

Make sure Docker Desktop is running. From the project root:

```bash
docker compose up --build -d
```

Visit http://localhost:5000. Stop the container with:

```bash
docker compose down
```

The SQLite database is stored in the named Docker volume `campuscare_data`, so it remains available when the container is recreated. To remove the volume and its data too, use `docker compose down -v`.

To build and run without Compose:

```bash
docker build -t campuscare:latest .
docker run --name campuscare -p 5000:5000 -e CAMPUSCARE_ADMIN_PASSWORD=admin123 -v campuscare_data:/data campuscare:latest
```

## Jenkins CI pipeline
1. Install Jenkins on a machine/agent that has Python, Git and Docker available.
2. Create a Pipeline job.
3. Configure the job to use Pipeline script from SCM (Git) and provide this repository URL.
4. Set the script path to `Jenkinsfile`.
5. Run Build Now.
6. The pipeline checks out the repository, creates a virtual environment, installs requirements, runs unit tests and builds the Docker image.

The Jenkins agent must have permission to execute Docker commands. If Docker is not available on the agent, the Docker build stage will fail; configure Docker on the agent or temporarily disable that stage for a Python-test-only CI demonstration.

## Important security note
This is an educational prototype, not a production helpdesk. It uses a shared admin password and does not yet implement CSRF protection, rate limiting, account management, email verification or audit logs. Set a strong secret key and admin password for any demonstration beyond your own machine. Do not enter real personal or confidential information.
